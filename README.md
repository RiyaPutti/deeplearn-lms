# 📖 Overview

DeepLearn LMS is a modern interactive learning platform designed to help learners master:

- Deep Learning
- Neural Networks
- Sequential Models
- Transformers
- LLMs
- RAG Systems
- AI Agents
- Modern Generative AI

This platform was built as a frontend-focused educational LMS using React and Vite with a strong focus on:

✅ Structured learning  
✅ Clean UI/UX  
✅ Interview preparation  
✅ Hands-on practice  
✅ Topic navigation  
✅ Search functionality  
✅ Learning progression tracking  

The goal of this project is to provide a roadmap-style learning experience where users can progress phase-by-phase from beginner neural network concepts to advanced Generative AI systems.

---

# ✨ Features

## 📚 Structured Curriculum

The curriculum is divided into multiple phases:

### Phase 1 — Neural Network Foundations
- Perceptrons
- Feedforward Neural Networks
- Forward Propagation
- Backpropagation
- Activation Functions
- Loss Functions
- Optimizers
- Batch Normalization
- Regularization

### Phase 2 — Sequential Deep Learning
- Embeddings
- Vanilla RNN
- LSTM
- GRU
- Seq2Seq
- Attention
- Transformers

### Phase 3 — Modern NLP & Generative AI
- Tokenization
- BERT
- GPT & LLMs
- Fine-Tuning
- LoRA / QLoRA
- RAG Systems
- Vector Databases
- AI Agents

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/deeplearn-lms.git
```

---

## Navigate Into Project

```bash
cd deeplearn-lms
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```
